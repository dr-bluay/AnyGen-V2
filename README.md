# AnyGen - V2

AnyGen - V2 is a lightweight demo tool that generates randomly formatted AnyDesk-style addresses for testing, demonstrations, and educational purposes.

Features

- Randomly generated demo addresses
- Simple and lightweight interface
- Useful for UI testing and demonstrations
- Does not generate real or valid AnyDesk connection addresses

Demo Use Only

AnyGen - V2 is intended strictly for demonstration, development, and educational purposes. Generated values are random and should not be treated as real device identifiers or used to attempt unauthorized access to any device.

The developer is not responsible for misuse of the tool.
